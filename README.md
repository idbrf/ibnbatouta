# موقع وكالة كراء السيارات ابن بطوطة
**Agence de location de voitures Ibn Batouta**

موقع إلكتروني عصري وتفاعلي متكامل لوكالة كراء السيارات "ابن بطوطة" بالمغرب، مصمم بأحدث معايير الويب والتجاوب مع جميع الشاشات (الهواتف، الأجهزة اللوحية، والحواسيب) بدعم كامل للغة العربية (RTL).

---

## 🌟 أهداف الموقع وميزاته
- **الاطلاع على أسطول السيارات المتوفرة**: تصفح سيارات حديثة (2024) بمختلف الفئات (اقتصادية، عائلية SUV، فاخرة).
- **الحصول على معلومات وتفاصيل شاملة عن كل سيارة**: المحرك، نوع الوقود، ناقل الحركة، سعة الركاب والأمتعة، التكييف، ومزايا الأمان.
- **التواصل السهل والسريع مع الوكالة**: نموذج تواصل، أرقام الهاتف، واتساب بنقرة واحدة، وخريطة الموقع.
- **نظام حجز تفاعلي فوري**: حساب تكلفة الكراء الإجمالية بناءً على تواريخ الاستلام والتسليم والإضافات المختارة.

---

## 📄 صفحات الموقع
1. **الصفحة الرئيسية (`index.html`)**:
   - شريط علوي بمعلومات التواصل وساعات العمل.
   - قسم ترحيبي (Hero Banner) مع شريط بحث وحجز سريع.
   - عروض حصرية وسيارات جديدة مع شارات الخصومات.
   - تقديم الوكالة وتاريخها المستوحى من الرحالة "ابن بطوطة".
   - استعراض كافة الخدمات (كراء قصير وطويل الأمد، تسليم المطار، تأمين شامل، مساعدة 24/7، سائق خاص).
   - آراء وتقييمات العملاء.

2. **صفحة سياراتنا (`cars.html`)**:
   - عرض قائمة الأسطول المتوفر مع صورة كل سيارة، الماركة والطراز، السعر اليومي بالدرهم (MAD).
   - زر **"احجز الآن"** يفتح نافذة حجز ديناميكية تتيح تحديد التاريخ وحساب السعر وتأكيد الحجز.
   - زر **"التفاصيل"** يفتح نافذة المواصفات التقنية الكاملة والتجهيزات.
   - شريط بحث وفلترة متقدمة حسب: الماركة (Dacia, Renault, Peugeot, Hyundai, VW, Mercedes...)، الفئة، ناقل الحركة، والفرز حسب السعر.

3. **صفحة اتصل بنا (`contact.html`)**:
   - **نموذج تواصل متكامل** يحتوي على:
     - الاسم الكامل
     - البريد الإلكتروني
     - رقم الهاتف وموضوع الرسالة
     - نص الرسالة مع فحص الحقول وإشعار تأكيد فوري.
   - **معلومات الاتصال الرسمية للوكالة**:
     - **العنوان**: شارع المقاومة قرب مسجد محمد السادس
     - **الهاتف**: 0536792525 (قابل للنقر للاتصال المباشر)
     - **البريد الإلكتروني**: locaibnbatouta@gmail.com
     - **ساعات العمل**: يوميا من الثامنة صباحا الى الثامنة ليلا
   - خريطة تفاعلية توضح موقع الوكالة بشارع المقاومة.

## 🚀 كيفية تشغيل الموقع

### الطريقة الأولى: الفتح المباشر في المتصفح
يمكن فتح أي من ملفات HTML مباشرة في المتصفح (Chrome, Edge, Firefox, Safari) بالنقر المزدوج على:
- `index.html`
- `cars.html`
- `contact.html`

### الطريقة الثانية: تشغيل الخادم المحلي المدمج
افتح سطر الأوامر (Terminal أو PowerShell) في مجلد المشروع ونفذ:
```bash
node server.js
```
ثم افتح الرابط:
**http://localhost:3000**
